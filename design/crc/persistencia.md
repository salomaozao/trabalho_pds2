# RepositorioSaves

Grava e recupera heróis em arquivos texto no formato `chave;valor`.

| Responsabilidades | Colaboradores |
|-------------------|---------------|
| Conhecer o diretório onde os saves ficam | `Heroi` |
| Converter o nome do herói em um nome de arquivo seguro | `Item` |
| Escrever o herói completo: atributos, recursos, ouro, estatísticas, equipamentos e inventário | `Atributos` |
| Ler um save e recompor o herói, validando cada campo | `ArquivoInvalido` |
| Manter um índice com os nomes dos heróis salvos | |
| Listar, verificar existência e remover saves | |
| Traduzir qualquer erro de leitura em `ArquivoInvalido` com a origem do problema | |
