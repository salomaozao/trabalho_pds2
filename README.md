## Estrutura do repositório

- `include/` — headers (.hpp) dos módulos
- `src/` — implementação (.cpp) dos módulos
- `tests/` — testes automatizados
- `design/` — user stories e cartões CRC
- `data/` — arquivos de dados do jogo (itens, monstros, saves)
- `docs/` — documentação gerada (Doxygen)
- `scripts/` — scripts auxiliares
